# Shooping Mall

Boutique en ligne de vente de montres (Next.js 14, noir et jaune). Tel : 0522364759

## Lancer

```bash
npm install
cp .env.example .env   # puis remplir EMAIL_PASS
npm run dev
```

Le fichier `.env` contient vos identifiants e-mail (envoi des commandes/messages via Gmail). Il est ignore par git et n'est jamais publie. Pour Gmail, utilisez un **mot de passe d'application**.
